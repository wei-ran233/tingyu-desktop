# 插件安装与升级影响预览

[SDK 索引](README.md) · [当前计划](../plans/当前计划状态与后续实施清单-2026-10-21.md)

本功能属于 Host 安装管理，不增加隔离插件 API。公共运行时版本仍为 1.12.0。

在插件管理中选择签名 `.lxplugin` 包后，宿主先校验清单、签名、API 与原生包构建身份，再基于当前注册表和候选清单计算声明影响。预览不安装候选、不调用其运行时、不读取凭据内容，也不执行设置迁移。

确认框显示新增/移除权限、设置版本与迁移要求、凭据键声明变化、扩展点/扩展变化、必需依赖与冲突引起的声明可用性变化、可选集成变化，以及启用插件及其必需依赖者的预计重建范围。可选目标缺失、版本不满足或声明不可用不阻断其所有者的独立功能。升级保留原有启停选择。

这些是声明预估；运行时激活、真实外部服务和设置迁移的实际结果仍以安装事务和运行状态为准。设置版本增长只说明安装时需要迁移，不保证成功。预览不显示参数值、默认值或凭据值。

## 预览和确认的绑定

确认令牌在宿主内保存包路径、签名者、归档哈希与注册表上下文指纹，并有有效期且只能消费一次。确认时再次校验；串行提交事务开始时再次核对上下文。安装、卸载、升级、回滚、启停或签名/包资源改变后，旧审批不能直接执行，必须重新预览。普通设置值改变不单独使声明预览过期。

预留原生包 ID 必须匹配构建身份与可信签名，不兼容包不能进入确认安装。设置版本降级及安装器会拒绝的同版本 schema 漂移会提前报错；清单名称与作者仅以清理过的单行字段显示。

归档在预览后改变也会被拒绝；同名同版本不能绕过实际字节检查。校验失败不会把候选写入注册表。已有生命周期的取消与协调机制仍然有效，拒绝审批不代表从未发生内部暂停/恢复。

可用性变化与可选依赖变化合计最多 64 条；超过上限直接拒绝自动确认，不截断后继续安装。预计重建仅是启用状态和必需依赖的声明闭包，不枚举所有运行时故障与可选集成内部重连。

## 范围与后续

本增量完成 E6a 安装影响预览。完整能力目录、兼容矩阵、更多开发模板及 E7 各业务的公开扩展点继续按清单推进。安装回滚、参数快照与凭据的范围分别见对应 SDK；预览本身不提供任意业务副作用回滚。
