# 插件凭据存储 SDK 1.12

[插件 SDK 索引](README.md) · [实施计划](../plans/插件凭据存储实现计划-2026-10-22.md)

API `1.12.0` 增加独立凭据声明、系统加密存储和运行时按身份读取。凭据与普通 `settings`、插件 `storage` 分开管理，不进入 [参数导入导出](插件参数导入导出SDK-1.10.md) 或 [设置迁移快照](插件设置自动迁移SDK-1.11.md)。本增量不修改原生电台已有 vault 的保存语义。

## 声明

```json
{
  "apiVersion": "1.12.0",
  "permissions": ["credentials.scoped"],
  "credentials": [
    { "key": "apiToken", "title": "服务令牌", "description": "仅用于此插件的服务", "maxLength": 512 }
  ]
}
```

示例省略插件 ID、入口和签名等既有必填项。显式 `credentials`（包括空数组）和 `credentials.scoped` 权限均要求 API 主版本1、最低1.12；声明必须有权限。最多16项，key沿用设置键规则并拒绝原型键、重复键及与普通设置重名。标题为非空字符串、最多80字符，说明最多500字符；`maxLength` 可选，范围1..4096，读取/保存时缺省4096。清单不允许默认凭据、`value`、`exportable` 或其他未知字段。旧清单不补字段，旧签名兼容性保持。

凭据值为非空字符串，受声明长度及UTF-8最多16384字节限制。作者应使用稳定键；普通设置迁移不重命名、转换或导出凭据。移除声明后不能读取该键；同签名者的旧版重新声明时仍可读取保留值。用户可清空此身份的全部凭据，回收旧版本已移除的键。

## 用户管理与运行时

宿主插件设置页显示密码输入、已配置状态、保存/删除及存储状态刷新。已有值不回填、不提供显示明文按钮；输入提交后立即清空。单项删除与“删除全部凭据”不同，后者经原生对话框确认，默认取消，并删除当前身份的全部键。普通“恢复默认参数”保留凭据。

管理IPC只允许宿主窗口。状态读取损坏文件失败时仍可使用全部清空入口恢复。状态仅返回 `{available, configured}`，写入、删除和清空绑定页面当前签名者指纹，主进程在事务执行时重新验签和核对，防止页面打开后身份变化。签名插件在停用或初始化失败时也可管理凭据，便于修复必需凭据后重新启动。

隔离运行时通过当前调用上下文读取：

```js
void lxRuntime.start({
  activate: async context => {
    const token = await context.credentials.get('apiToken')
    // 缺失返回 undefined；加密存储锁定或损坏时拒绝。
    // 只在需要时使用此值，不将其写入日志或返回公共业务结果。
  },
  handlers: {}
})
```

此接口不接受插件 ID 或签名者参数，也不提供运行时写入/删除。仅已注册的顶层运行实例、已声明权限和键、启用且处于 active/activating 的签名插件可读取。运行时启动期间允许读取，避免必需凭据无法用于初始化。未声明键、未签名开发目录、非注册窗口、iframe、已撤销运行实例均拒绝；页面 `lxPlugin` 桥接没有凭据读取接口。

保存或删除会撤销旧运行实例及其请求，再重建实例；读取跨异步I/O后重新核对包、变更代次、实例和权限，撤销后的结果不能继续返回。每插件最多16个并发运行时读取，其余报忙。参数上下文、目录、事件或设置通知不会自动注入凭据。

插件在被授权后能读取自己的明文，因此作者可以将其写入自身业务输出；本协议的身份隔离不能代替用户对插件作者的信任，也不提供通用外部服务代理。现有运行时网络隔离规则仍适用，新增凭据权限不额外开放网络。

## 存储与生命周期

- 命名空间由插件 ID 和实际验签得到的签名者SHA256共同决定；文件名为该组合的SHA256。密文内部绑定插件ID、签名者、键和值，跨插件、签名者或键替换密文会被拒绝。
- 使用Electron `safeStorage`；Linux `basic_text` 视为不可用。不可用时拒绝保存和已有密文解密，不降级到明文或会话保存。缺失键返回undefined；状态查询及删除不需要解密。
- 每身份最多16键，文件最多512KiB，读取有界且拒绝非普通文件；支持 `O_NOFOLLOW` 的平台拒绝末级符号链接。写入使用独占随机暂存文件、0600权限和rename，失败清理暂存并保留旧文件。底层错误统一为不含凭据或密文的错误。
- 同签名者升级和回滚保留凭据，凭据不随参数快照回退。卸载先清理当前身份命名空间，清理失败保留插件身份以便重试；包目录、storage与设置清理成功后才移除注册记录，清理或最终提交失败保留身份可重试；已经删除的凭据或包文件不自动恢复，会明确提示。当前安装器拒绝同ID换签名者更新，卸载后的另一签名者也不能读取原身份密文。
- “删除全部”可在无声明字段时回收历史键；达到16键上限需要先清理历史键。只有旧身份遗留文件、外部备份、进程异常终止留下的暂存文件不属于完备审计/安全擦除保证，系统加密并不保证抵御同用户已控制的主进程或操作系统。

## 验证入口

`npm run test:collection` 包含声明、vault和service测试。生产main/renderer构建后运行 `npm run test:plugin-credentials:app`，以 `LX_PLUGIN_CREDENTIALS_EVIDENCE_DIR` 指定独立目录。测试使用虚构凭据、签名夹具和临时profile。实际系统密钥环不可用时先验证拒绝分支，其余实机流程可通过脚本注入AES测试适配器；报告必须区分两者，不把测试适配器结果写成系统密钥环验收。

实际结果见 [本轮验收记录](../records/插件凭据存储实现与验收-2026-10-22.md)。跨schema备份导入、复杂设置转换、凭据密钥轮换、外部服务专用代理仍待续。
