# LX Music Desktop · 自定义修改版

本项目基于 [LX Music Desktop](https://github.com/lyswhut/lx-music-desktop)，使用 Electron、Vue 3 与 TypeScript，围绕界面、播放体验、AI 电台和插件扩展进行改进。

当前源码版本为 **2.12.3-beta.12**，以 [package.json](package.json) 为准。源码版本、本地安装和 GitHub 已发布版本需分别核对；发行文件请到 [本仓库 Releases](https://github.com/wei-ran233/lx-music-desktop-style-change/releases) 查看。

## 项目能力与实现入口

- **音乐功能**：搜索、歌单、我的列表、排行榜、下载、播放详情和设置纳入官方原生整合包；功能模型与页面渲染分开。
- **AI 电台**：独立的 `lx.radio` 原生插件提供对话、音乐推荐、历史、偏好与语音；接入说明见 [电台指南](doc/features/ai-radio.md)。
- **插件扩展**：隔离页面、集合视图、主题、参数设置，以及 processor、provider、action、event 与声明式 UI 扩展；当前宿主 API 为 `1.12.0`，支持范围见 [SDK 索引](doc/plugins/README.md)。
- **主题与界面**：保留原版表现，支持功能的多种渲染与主题外观；相关设计和验收见 [记录索引](doc/records/README.md)。

原生整合包与隔离运行时插件有不同的能力边界。具体功能的可用性、网络服务与兼容限制，以当前实现和对应验收记录为准。

## 开发启动

项目要求 Node.js `>=22`、npm `>=8.5.2`。在仓库根目录执行：

```bash
npm ci
npm run dev
```

开发启动会先生成开发插件包。正式全量构建 `npm run build` 要求外部正式签名密钥，分项编译与平台打包流程见 [开发指南](doc/guides/development.md)。
