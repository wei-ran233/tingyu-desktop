# 开发与协作指南

[返回文档总索引](../README.md)

这些指南描述当前仓库的工作方法。首次接手先看 agent 工作指南，再根据任务选择环境、验证或文档维护说明。

| 文档 | 用途 |
| --- | --- |
| [Agent 工作指南](agent-workflow.md) | 阅读顺序、变更定位、已有工作保护与交付标准 |
| [开发指南](development.md) | 环境要求、开发启动、分项构建和正式打包边界 |
| [验证指南](validation.md) | 按变更选择测试，区分契约、Electron、联网和安装验收 |
| [文档维护约定](documentation-maintenance.md) | 分类规则、状态说明、旧路径对照与链接检查 |

新增指南应围绕可复用的操作流程。某一次修复的过程与测试结果放入 [records/](../records/README.md)，尚待交付的设计放入 [plans/](../plans/README.md)。
