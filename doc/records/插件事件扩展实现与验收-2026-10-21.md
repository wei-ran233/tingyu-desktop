# 插件事件扩展实现与验收

日期：2026-10-21（Asia/Singapore）。对应[事件实施计划](../plans/插件事件扩展实现计划-2026-10-21.md)和[当前清单 E1](../plans/当前计划状态与后续实施清单-2026-10-21.md)。协议见 [SDK 1.6](../plugins/插件事件扩展SDK-1.6.md)。

## 代码交付

API 升为1.6.0，新增 event 扩展点、events.publish 与 extensions.subscribe 权限，以及 PluginEventReceipt；旧包清单与签名保持兼容。清单验证 event 的空 acknowledgement schema、API 门槛和拥有者发布权限；跨包目标权限、依赖和点版本由生命周期按实际 owner 契约检查。

PluginLifecycle 新增 publishEvent：每拥有者 FIFO、发布时订阅快照、独立 clone、每 handler2秒、队列16/全局64/订阅贡献64、payload64KiB。超限拒绝不隔离；订阅者异常、非法 ack 或超时隔离故障链，其他订阅者继续。settings/lifetime 信号撤销旧投递；新实例和晚激活订阅者不接收旧事件。

运行时后端向每个真实 sender 绑定拥有者发布闭包和生命周期 signal，preload 的 context.publishEvent 只经过受限运行时桥；普通页面没有新事件 IPC。搜索灵感1.2.0在换组后发送 suggestions.changed，provider 读取和单独修改设置不会触发通知。换组不等待订阅处理，避免故障接收方拖慢动作。

独立 worker 编写 plugin-event-tests.ts 和 plugin-events-app.cjs，主线审阅、接入并实际执行；不能仅以 worker 报告作为验收。

## 保留的失败与修复

初次 Electron 在执行环境内被 sandbox_host_linux.cc 的 Operation not permitted 阻止，尚未进入应用；获准在可运行桌面沙箱的环境重试，未加 --no-sandbox。

新应用脚本第一次重试漏加载 dist/main.js，导致等待空应用超时；主线补齐实际入口后重跑。下一轮已通过事件身份、克隆、FIFO、隔离等前7组，重启场景因测试夹具未释放新实例的激活门闩超时；主线改为异步启用、等待并释放门闩后再等待启用完成。保留 app.log、app-retry.log、app-final.log 与各自结果，不把这些失败改写为成功。

契约测试初次将外部点类型判断放在单包清单验证，修为在生命周期验证；全局容量测试初次误提交65个预期成功请求，修为先提交64个再验证第65个拒绝。新测试的lint命名与void推导问题已修复，覆盖语义保持。

## 独立审查与数据边界补强

独立审查发现原 object schema 只检查可枚举属性，空对象会误接受 Date/Map/Set/ArrayBuffer，JSON计数无法覆盖其中的结构化载荷。该发现纳入本轮修复：限制普通JSON对象和数组，拒绝非标准原型、隐藏字段、symbol及访问器，按数据属性递归匹配。增加非JSON输入/ack与消息信封大小边界检查；以补强后的最终构建及复测结果为准。此前通过记录保留，不能代替修复后的复测。

最终补强后98项契约通过，新增14组事件契约；真实Electron事件13组通过，unexpectedErrors=[]，包括Map/Date/ArrayBuffer输入和ack拒绝、payload小于64KiB但信封超限拒绝。独立审查对原缺陷的限定复审静态通过，主线随后以真实构建复测；复审原文保存于review-final.md。

修复worker在写入两个文件后返回“exceeded retry limit, last status: 429 Too Many Requests”，未交付完成报告，不据此推断额度耗尽。主线核对已写入内容并接回，修正descriptor返回类型和测试夹具/类型，执行最终验证；不把中断worker当作完成。

子agent请求均为DeepSeek V4.1 Flash/max、fork_context=false；会话有效模型与真实工具调用摘要见subagent-audit.json。该文件不宣称已完整验证历史隔离。独立审查复审通过后会话已不可用，关闭调用返回not found；不作为待运行agent继续占用或等待。
