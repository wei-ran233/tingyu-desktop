## 实现范围

E6a 已实现安装/升级前的声明影响分析及确认绑定。公共运行时 API 保持 1.12.0。纯函数按当前清单与验签候选计算权限增减、必需依赖/双向冲突的传递阻断与恢复、可选目标声明状态、设置版本、凭据键和扩展声明变化，以及启用的必需依赖闭包的预计重建。可用性与 optional 变化合计最多 64 条，超过即拒绝，不截断后静默确认。

Host 预览不写注册表、不安装候选、不启动其运行时、不读参数文件或凭据内容。确认 token 绑定签名者、实际归档 hash 与注册表上下文，限时且一次性消费；入口和串行提交内均复查。上下文包含完整 canonical manifest、文件摘要、启停和来源，包含 development 仅改清单的情况，不纳入实时参数值。安装直接调用也默认绑定本次验签的包字节。

预留原生 ID 必须携带匹配的 nativeBundle ID、构建 hash 与实际验签的可信指纹；预览和直接安装均在进入变更前拒绝不匹配包。设置版本降级和同版本 schema 漂移按安装器现行条件提前拒绝；版本增长只预估需要迁移，不执行迁移，也不保证真实值可迁移。

确认框由宿主生成影响内容。名称与作者独立呈现，清理控制字符、换行分隔符与双向控制字符，避免清单名称伪造权限段落；文本不作为 HTML 解释。

## 实际验证

- 总契约 209 项、适配 8 项通过。其中新影响/展示检查 7 组，新预览服务检查 11 组。
- 服务测试包含只读预览、签名/API/native build 检查、预览期间重试、即时/排队后过期审批拒绝、生命周期协调恢复、development manifest-only 变更、包字节替换、普通设置变更不使声明审批过期、降级/同版本漂移早拒绝。使用临时文件及虚构数据。
- 生产模式 main/renderer 编译、main/renderer TypeScript 与定向 ESLint 通过。开发签名样例与原生构建身份重新生成。
- Electron 41.2.0 加载 `dist/main.js`，临时 profile、真实签名包、真实 Vue 确认框：6 项通过，包含权限/必需与可选影响、过期审批、归档变化、恶意名称/作者展示、取消不替换、确认后依赖状态。证据 `.runtime/plugin-impact-20261023/app-delivery/app-results.json` 与 `impact-preview.png`，无捕获的渲染异常。
- 复核补齐可信原生 radio 包通过实际 service 预览/安装的正向检查，错误 native ID 在清单校验层拒绝；设置漂移与降级也覆盖直接安装早拒绝。

独立复核指出的原生包门禁、开发清单上下文、设置预览一致性和名称欺骗均修复并加入回归。

预估不是运行时健康或外部服务验收；内部取消可先暂停实例再由协调恢复。未验证所有插件组合、所有在线服务、安装包或日常配置迁移。完整能力目录、兼容矩阵、更多模板与 E7 业务公开扩展仍继续按清单推进。
