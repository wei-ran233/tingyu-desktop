# 接口真实调用测试与优化

日期：2026-10-20

## 测试范围

在生产构建的 Electron 应用中，使用一次性配置目录，复用安装版的音源、DJ 模型、天气和语音接口配置。测试关键词固定为“成都”，模型请求只包含接口连接测试文本，不发送聊天历史、用户画像或私人歌单。测试报告不记录密钥、签名播放地址和音频正文。

安装版保持运行，测试没有改写其配置。临时配置中的代理调整仅用于比较直连与代理结果。

上述音频结果对应本次测试歌曲与当前返回地址，不能推广为该音源的所有歌曲均可播放或均不可播放。五个来源的完整曲库、付费内容、连续播放、下载传输和长文本合成没有逐项验收。

## 已实施的优化

1. 酷狗分组搜索原先错误地用父条目的标识去重子条目，导致子条目被全部跳过。现改为按子条目去重，并兼容没有 `Grp` 的结果。
2. 搜索返回 HTTP 成功但 JSON 结构异常时，有限次数重试，避免把结构异常当成有效列表。
3. HTTP 请求准备阶段抛出异常时，公共 Promise 现在会拒绝，避免一直等待或产生未处理拒绝。
4. 生产环境关闭无条件完整请求 URL 输出；调试输出也移除查询参数。
5. “测试天气”现在直接使用表单快照，不再先保存设置。城市搜索也使用正在编辑的 Host / Key；缓存按配置隔离，修改草稿不会污染已保存设置的缓存。
6. TTS 网络错误提示明确指向网络／代理设置；凭据解密失败提示可以解锁密钥环或重新填写，而不直接暴露底层英文加密错误。

## 代理条件与剩余问题

安装版当前自定义代理开关关闭。火山语音在本次网络环境中需要经过本机现有代理。可以在“设置 → 连接与同步 → 网络设置”启用自定义代理，主机 `127.0.0.1`，端口 `7897`，再执行语音测试。本轮没有改变安装版的该开关。

酷狗／QQ／咪咕的失败发生在自定义源返回的资源地址阶段，需要刷新链接、换用可用资源或修复／更换该自定义源；仅凭 URL 字符串不能宣称播放接口完全正常。
