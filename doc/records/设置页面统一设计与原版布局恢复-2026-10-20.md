# 设置页面统一设计与原版布局恢复

日期：2026-10-20

## 设计依据

以 Git HEAD 中插件化之前的 LX 页面和 DJ 设置弹窗为参照。维持已有主题、原生界面密度和导航习惯，调整重复导航和表单排版。

- 色彩沿用主题变量。默认绿色主题参考：主色 #4EB584、白色面板 #FFFFFF、浅底 #F2F8F5、边界 #DDEBE3、正文 #25372F、次级文字 #7B8B83；实际随用户主题变化，不硬编码这些颜色。
- 字体继承应用字体，正文 13px、辅助 12px、页标题 15px，避免紧凑视图嵌套导致字号累乘。
- 设置容器由统一标题栏、160–176px 导航栏、滚动参数区、底部操作区组成。控件保持相同边距、高度、标题层级和焦点样式。
- 页面采用六组一级分类，展开当前组的二级菜单；电台的六类参数直接放进二级菜单，右侧不再嵌套第二套设置导航。
- DJ 设置弹窗保留原有尺寸、左菜单、右参数、底部取消/保存。弹窗与设置页共用电台参数模型和唯一一份模板。

```text
设置 / 当前分类                          当前参数标题
┌─────────────────┬─────────────────────────────┐
│ 常规             │ 参数组标题                   │
│ 播放与歌词       │ 参数名称                     │
│ 音乐与下载       │ 控件与帮助文字               │
│ 电台             │                             │
│   模型与 API     │                             │
│   DJ 人设        │                             │
│   语音播报       ├─────────────────────────────┤
│ 连接与同步       │ 自动保存提示 / 保存配置       │
│ 维护与扩展       │                             │
└─────────────────┴─────────────────────────────┘
```

复核：取消独立“卡片式设置页”和密集的全分类页签，保留 LX 的简单分栏结构。集合提供器是可选渲染，新配置默认使用官方原版列表；已明确选择的提供器不强制改写。功能插件架构保留。

## 实施与验收

实施及真实 Electron 截图证据保存在 `.runtime/settings-design-20261020/`。

- 17 个设置入口共用一致的滚动参数区和底部操作区，基准正文 13px、左右留白 24px、底部操作区 58px。
- 六组一级菜单和二级参数菜单通过真实窗口检查；电台六类参数切换保持同一个设置模型和未保存草稿。
- DJ 弹窗与设置页使用同一份参数模板；弹窗保留左菜单／右参数／底部取消保存。
- 亮色设置选中菜单文字对比度约 8.88:1，暗色约 6.49:1。760×650 窗口检查通过。
- 设置的渲染切换、插件停用／恢复和独立电台运行时测试纳入完整应用脚本。

按用户后续要求，主题验收只覆盖亮色与暗色。其他主要页面的调整和测试见 [主要页面统一设计与验收](主要页面统一设计与验收-2026-10-20.md)。
