# 插件声明式 UI 扩展实现与验收

日期：2026-10-21（Asia/Singapore）。对应[实施计划](../plans/插件声明式UI扩展实现计划-2026-10-21.md)、[SDK1.7](../plugins/插件声明式UI扩展SDK-1.7.md)和[当前清单E2](../plans/当前计划状态与后续实施清单-2026-10-21.md)。

## 交付与范围

API1.7新增renderer/slot/toolbar三类声明式UI点与extensions.render权限。清单严格限制输入输出schema，生命周期按明确qualified id执行，复用必需依赖、精确版本、单实现busy、超时、settings取消和故障隔离。

宿主公开搜索灵感区域的三个白名单点，快照只含source/建议词/动作id和title。输出为list/grid/row、标题和text/search/action条目；按钮只能引用快照公开的能力。宿主用自身Vue组件绘制插值文本，点击时再按当前模型复核，不允许插件注入HTML、CSS、URL、组件、脚本或宿主对象。

默认关闭的lx.search-layouts提供列表、卡片、说明与工具栏；用户启用后仍须手动选择。选择独立于主题保存，停用/失败恢复原生，保留偏好；再次可用后重新呈现。更换该区域渲染不重建搜索模型或改变搜索灵感分组。新增4种语言的选择控件文字。

本轮是E2受限JSON呈现的搜索试点，不代表任意第三方Vue组件或所有页面插槽均可用。其他业务需显式定义快照、命令和宿主挂载位置；E3–E7仍待推进。

## 保留的失败与修正

- 初次renderer构建遇到新接线的类型/ESLint问题；定向修复调用泛型、JS动作数组类型、Vue回调类型及格式，最终构建通过，保留初次日志。
- 独立应用脚本最初使用plugin:*频道，主线按真实模块映射修为plugin_*后才执行。未将worker的node --check作为真实IPC验收。
- 首次应用跑过前三组，在主题检查返回Vue proxy时出现“An object could not be cloned”；改为布尔谓词，保留app/记录。
- 再次应用跑过主题检查，恢复后异步刷新中的瞬态空文档被直接读取；改为等待可观察文档就绪，保留app-retry/记录。最终app-final/通过。
- 新严格测试中的assert.deepEqual(calls,[])导致TypeScript将数组缩窄为never[]，改为断言length，不改变行为验证；随后严格检查通过。
- 临时profile首次不存在SQLite文件时，数据库初始化先以fileMustExist打开而记录SQLITE_CANTOPEN，再正常创建数据库并完成初始化；本轮实际UI已运行，不将这条首次尝试日志当作最终数据库故障。

## 决策与限制

选择受限声明式JSON呈现，避免把原生Vue注册器交给隔离插件；代价是任意布局、CSS和组件尚不支持，增加表达力必须另行版本化。主题保留用户选择，本轮没有增加主题指定第三方UI的覆盖协议。

取消仅撤销输出和通知运行时，不回滚已发生副作用。当前页面级IPC没有AbortSignal，宿主用最新加载器忽略旧响应；停用/更新/settings变化仍由生命周期取消。每个点最多显示32个可用候选，文档最多24个条目；扩展生态放大前应评估分页目录和更丰富布局。

本轮未提交、推送、安装、修改日常配置或正式发布。源码、本地生产构建与临时profile验收分别完成；开发签名不是正式发行。
