# 插件数据提供器验收（2026-10-21）

## 本轮实现

插件 API 由 1.3.0 升级到 1.4.0，保留旧版兼容。增加通用 provider 扩展类型及 extensions.provide 权限；运行时沿用签名、必需依赖、隔离、超时、取消与失败隔离机制。provider 可以使用不同输入和输出 schema，并支持有上限的数组数据。

新增默认关闭的 lx.search-starters（搜索灵感）签名插件，提供搜索空白页的搜索词。插件只返回数据，页面负责显示和点击搜索；原版与潮汐等主题复用共享功能逻辑与空白页组件。用户在统一插件设置中启用并编辑搜索词，停用后即时移除，原参数保留。

多个 provider 按优先级升序，再按插件 ID 和扩展 ID 排序，只调用首个可用提供器。当前调用失败时抛错并隔离故障插件，不在同一次调用中悄悄尝试其他插件；下一次调用可以选择剩余健康提供器。无提供器时搜索宿主返回空列表，现有热搜、历史记录和手动搜索不受影响。

## 实施边界

已实现通用 processor 和 provider；通用 action/event、动态 renderer/slot/toolbar 注册、动态主题 assets/layout/motion 协议、可选依赖、配置迁移和凭据存储仍待实现，不能宣称“万物皆可扩展”。

本轮使用临时测试配置，只更新工作区与 dist，没有修改真实用户配置、替换系统安装、提交或发布版本。
