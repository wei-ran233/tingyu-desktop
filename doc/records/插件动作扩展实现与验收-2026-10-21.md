# 插件动作扩展实现与验收（2026-10-21）

本轮新增 API 1.5.0 通用 action 和默认关闭的搜索灵感插件“换一组”，源码及本地生产构建已完成；未替换系统安装、修改日常配置、提交或推送代码。此前的原始计划保持保存，本轮是第二阶段的一个可验收增量，并非整个扩展计划完成。

## 已交付代码

- `src/common/plugin/types.ts`、`extensions.ts`：action、extensions.act、纯文本动作标题和 API 版本校验，兼容旧包签名和旧 API。
- `src/main/modules/plugin/lifecycle.ts`：listActions/act，明确 pluginId/extensionId 选择，单动作在途限流、超时、取消、非法输出隔离；不自动换实现或重试。
- `service.ts`、`index.ts`、`ipcNames.ts`、`src/renderer/core/pluginExtensions.ts`：宿主白名单调用，隔离页面没有任意动作 IPC。
- `plugin-samples/official-suite/manifest.json`：search.suggestions.next@1.0.0 动作点；`plugin-samples/search-starters/`：1.1.0 样例、每组数量设置、运行时分组和换组动作。
- 共享 `features/Search/components/BlankView.js`：加载、busy、错误、设置和页面变化的旧响应保护；`views/Search/components/BlankView.vue`：统一展示按钮。原版、主题渲染复用同一功能模型。
- 四种语言新增动作失败提示。插件说明页和 [SDK 1.5](../plugins/插件动作扩展SDK-1.5.md) 已同步。

搜索灵感依然默认关闭，在“设置 → 维护与扩展 → 搜索灵感”启用并设置搜索词和每组数量，然后进入空白搜索页使用“换一组”。默认八个词，每组四个，切换主题不重置运行时当前组；恢复默认参数回到默认第一组。
