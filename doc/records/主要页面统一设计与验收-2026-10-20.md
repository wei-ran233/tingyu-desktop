# 主要页面统一设计与验收

日期：2026-10-20

## 目标与边界

保留原版 LX 的导航、音乐表格、左侧目录、封面和 DJ 对话结构，在现有插件架构内统一页面层级、筛选区、边界与留白。功能模型与渲染仍分开，同一模型可切换渲染，原版列表在新配置中默认使用。

按用户最新要求，本次主题验收只覆盖亮色与暗色。沿用已有主题变量，不新增自定义主题适配规则。

## 页面调整

| 页面 | 调整 |
| --- | --- |
| 搜索 | 统一标题和音源／类型筛选；搜索历史及热门词支持键盘操作；歌曲结果保留表格 |
| 歌单浏览与歌单搜索 | 保留封面与描述的横排卡片，统一卡片留白、网格、焦点；窄窗口减小列宽 |
| 歌单详情 | 封面、标题、描述、播放／收藏／返回分区，按钮独立间距，窄窗口允许换行 |
| 排行榜 | 保留左侧榜单和右侧歌曲列表，统一页头、音源选择高度与分栏边界 |
| 我的列表 | 保留封面、目录元信息、操作区和原版表格；新增／更新列表按钮常显 |
| 下载 | 列表／卡片共用标题与筛选；卡片显示进度与可读状态，操作随状态变化；空列表有说明和搜索入口 |
| DJ | 保留历史侧栏、模式切换、欢迎区、输入框；历史分类分两行避免截断；状态背景减淡，模式选中文字在亮暗下可读 |
| DJ 可选对话渲染 | 对话行宽、消息间距、歌曲卡片、输入框及按钮统一，切换渲染保留同一功能模型 |
| 设置 | 继续使用统一工作区、六组一级菜单和二级参数菜单，详见设置设计文档 |

共用样式在 `src/renderer/assets/styles/pages.less`，通过显式类名应用于页头、工具栏和空状态。未全局覆盖虚拟列表行高，避免显示密度与定位计算不一致。

## 真实应用测试发现并修复的问题

1. 歌单浏览、歌单搜索的提取后功能模型没有注册 `SongList` 子组件。Vue 会把它当作未知元素，导致无卡片、滚动恢复调用到 DOM 原生 `scrollTo(number)` 报错。两处补齐组件注册。
2. 窄窗口调整后快速切页，虚拟列表的延迟 resize／animation frame 可能在卸载后运行。刷新函数现在先确认容器存在，再读取滚动位置。
3. DJ 历史分类在窄侧栏中横排截断，改为两列加末行通栏。暗色主题的模式按钮避免白字配亮底。
4. 下载卡片此前直接显示内部状态且所有任务均有开始／暂停按钮，现与列表使用相同的状态条件。

## 验收方式

真实 Electron 加载生产构建，使用一次性配置目录。默认列表使用真实 SQLite 的 120 首本地测试歌曲；下载测试写入一次性数据库的暂停、失败、完成任务，不启动传输。在线页面通过测试脚本替换已加载 SDK 的响应，提供 36 首测试歌曲和 9 张本地 SVG 封面歌单，不给生产代码添加测试接口。

覆盖搜索首页、歌曲搜索、歌单搜索、榜单、歌单浏览／详情／返回、我的列表、下载空状态／任务状态／筛选、DJ 两种渲染、1114×718 和 760×650 窗口，以及亮暗主题。还运行原有设置、插件停用／恢复及渲染切换模型保留测试。

验证产物位于 `.runtime/settings-design-20261020/`。在线测试数据只证明布局与对应交互，不代表真实在线搜索、音频播放、下载传输或云端模型／语音服务已通过验证。当前工作区包含源码和构建产物，没有替换系统安装的软件。
