# 插件参数恢复默认实现计划（2026-10-21）

## Global Constraints

- 复用当前工作区和已有修改，不提交、推送、安装或修改正在使用的软件配置。
- 只恢复选中插件通过 manifest.settings 声明的参数；不修改插件启用状态、其他插件参数或原生 DJ 等独立设置。
- 服务接口 resetSettings(id) 使用与 setSetting 相同的串行锁，成功删除该插件的参数覆盖文件后返回 schema 默认值。清除覆盖让未来包版本的新默认值自然生效。
- 参数确实变化时复用已提交设置通知、相关在途调用取消及实时刷新；相同参数不重复通知；文件错误必须抛出，不伪报成功。
- IPC 名 plugin_reset_settings，入参 {pluginId:string}，返回 Record<string,string|number|boolean>；仅宿主窗口可调用。公共插件 API 保持1.4.0，不增加隔离插件可调用的 reset 接口。
- 子 agent 只用已配置的 DeepSeek V4.1 Flash，max，不继承历史，不递归创建助手；多个写入者互不覆盖。
