## 协议与实现范围

API 1.6.0，兼容旧清单与签名。扩展点 kind=event，拥有者需 events.publish；订阅者通过 extensions 声明 target/version/handler，需 extensions.subscribe、必需依赖及隔离 runtime。input 是有界事件 schema，output 只允许空 object schema，handler 必须返回 {}。不开放动态任意频道订阅或宿主对象。

只有当前 active 拥有者可发布自己的点；发布桥绑定真实 runtime 的主 frame、生命周期 signal 和 sender，旧实例不能借同 ID 发布。激活中不能发布，宿主没有新增通用公开发布 IPC。订阅来自发布时 active 快照，无重放、持久化或恰好一次承诺。

每发布者 FIFO，每事件并行 fanout，每个 handler 上限2秒。队列含执行中最多16，全局最多64；最多64订阅贡献，payload上限64KiB，桥接整个消息也限制64KiB。超限拒绝 busy，不隔离；不自动重试。每个订阅获得独立数据 clone。

发布结果为 delivered/failed/skipped 贡献数。非法 ack、异常或超时隔离故障订阅者及依赖链，健康订阅者继续；运行时繁忙或已撤销的订阅记 skipped。拥有者停用/更新/相关设置变化取消排队和在途事件；订阅者停用/更新/设置变化跳过该订阅。取消不能撤销已完成的副作用。
