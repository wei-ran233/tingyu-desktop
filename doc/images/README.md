# 文档图片与截图

本目录保存项目图标和历史界面截图。根 [README](../../README.md) 引用 `icon.png`、`my_list.png`、`ai_dj.png` 与 `app.png`；保留这些文件路径，避免破坏页面资源引用。

截图展示拍摄时的界面，不能证明当前构建、安装状态或插件启用状态。新增公开截图应使用虚构、非敏感数据，避免露出密钥、私人歌单和聊天历史，并在引用处说明适用版本或拍摄背景。

本轮原始验收截图与日志宜放在独立的证据目录，并在 [records/](../records/README.md) 记录位置；需要长期随仓库分发的图片再挑选进入本目录。图片改名或搬移时同步检查 Markdown 与 HTML 的资源链接。
