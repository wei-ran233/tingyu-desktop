# 语音服务配置与故障修复

核对日期：2026-10-16。

## 配置入口与测试方法

进入 AI DJ → AI DJ 设置 → 语音播报。先选择渠道，填写对应服务自己的密钥和发音人，再点击“测试语音”。测试使用表单当前值，无需先保存；听到声音后保存配置。语音合成结果为 AI 生成。聊天模型的 API Key 不会自动用于语音服务。

本机实测 Electron 的 `speechSynthesis.getVoices()` 返回空列表，不能依靠默认“本地语音”播报中文。安装普通音频播放器或调整系统音量不能补齐这一语音能力。云端 TTS 可以绕过系统音色缺失。

## 可配置的正式服务

| 渠道 | 必填配置 | 发音人示例 | 注意事项 |
| --- | --- | --- | --- |
| Azure 神经语音 | Speech 资源 API Key、该资源所在的 Region | `zh-CN-XiaoxiaoNeural` | 区域必须与资源一致，不能照抄默认 `eastasia`；英文可用 `en-US-JennyNeural` |
| 讯飞在线语音合成 | AppID、API Key、API Secret | `xiaoyan` | 开通在线语音合成 WebSocket v2 对应服务及音色权限；本程序使用三项凭据的签名鉴权 |
| OpenAI TTS | OpenAI API Key | `alloy`、`nova` | 本程序使用 `tts-1`；服务商的网络和账号权限也必须可用 |
| 火山引擎 · 豆包语音 2.0（新版 API Key） | API Key，资源默认 `seed-tts-2.0` | 下拉列表选择 Vivi 2.0、小何 2.0、云舟 2.0 等 | v3 HTTP Chunked 接口，无需 AppID；内置官方公开音色目录，账号权限由试听校验 |
| 火山引擎 TTS（旧版） | AppID、Access Token | `BV001_streaming` | 当前实现为 `/api/v1/tts`、`volcano_tts` 集群；需要旧版 v1 对应权限，不适用于只有 v3 API Key 的新账号 |
| 自定义 TTS | 完整接口 URL、按服务要求填写 API Key、发音人 | 由服务定义 | 当前按 OpenAI 兼容格式发送 `model: tts-1`、`input`、`voice`、`speed`、`response_format: mp3`，直接接收音频；不兼容任意 JSON 返回结构 |

Azure 操作步骤：在 Azure 控制台创建或选中 Speech 资源，从该资源的 Keys and Endpoint 页面获取 Key 与区域；应用里选择 Azure，填写这两项，中文语言选简体中文，发音人填 `zh-CN-XiaoxiaoNeural`，语速先设 1，点击测试。

讯飞操作步骤：在讯飞控制台创建应用并开通“在线语音合成”，使用同一应用的 AppID、API Key、API Secret 填入程序对应字段，发音人先用 `xiaoyan`。该实现使用 WSS；系统时间偏差或 IP 白名单也可能导致鉴权失败。

“有道翻译语音”是公共短句接口，本程序限制在 100 字以内，不作为长篇 DJ 播报的可靠方案。

## 修复内容

- 搜歌必须同时核对曲名与指定歌手，排除翻唱、伴奏、现场或混音等结果，不能把任意第一条搜索结果当作目标歌曲。
- 按规范化曲名去重，跨平台和同一首歌的不同歌手不会凑成两首推荐；模型重复工具调用在播放前即被拦截并反馈给模型。
- 本地推荐从熟知的热门或经典曲目候选中查找，只显示实际搜索核实成功的歌曲；近期推荐会跳过，没有命中时如实提示。
- 语音服务缺失配置、HTTP 失败、非音频响应会显式报错，不再静默退回没有音色的系统语音。
- 火山 v1 按顶层 `data` 字符串解码；自定义接口使用其宣称的 OpenAI 兼容格式；服务切换清空旧发音人，避免把 Azure 音色传给其他服务。
- HTTP 语音请求走应用主窗口的 Electron 会话，使应用的代理设置适用于该类语音请求；讯飞 WebSocket 仍采用其独立的连接实现。
- 恢复 75%–150% 界面缩放入口与比例计算；最大化状态切换窗口尺寸时等待恢复事件后应用尺寸。
- 当前 GNOME 会话为 Wayland，Electron 官方说明原生 Wayland 下聚焦可能只出现通知、程序调整窗口尺寸也可能被限制。检测到 XWayland 的 DISPLAY 时默认使用 X11 后端，并保留用户显式指定的 Ozone 后端。Linux 主窗口使用不透明背景；显示窗口时统一恢复、显示、聚焦并提升层级；应用启动关联统一 `desktopName` 与桌面条目，避免 Dock 将运行窗口与启动器分开识别。

## 动态音色目录

音色设置支持“刷新官方音色”和按名称、语言或 ID 搜索。程序在隔离、启用沙箱的网页读取器中加载官方公开文档并解析 TTS 2.0 表格，不向该页面发送 API Key。2026-10-17 实际读取到 466 个官方公开的豆包 2.0 音色。官网新增兼容音色后，刷新即可进入选择器，无需改源码重打包。

首次打开语音设置以及缓存超过 24 小时时会自动刷新，也可手动刷新。成功结果缓存到本地，网络或网页结构异常时保留当前列表并提示失败；当前已选音色不会因刷新或搜索而被清空。官方公开列表不等同于账号授权列表，是否有权使用仍以该音色的真实试听结果为准。
